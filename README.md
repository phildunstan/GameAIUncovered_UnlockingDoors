# Unlocking Doors

This project contains example door implementations as discussed in Chapter 15 Unlocking Doors of Game AI Uncovered Volume 5, authored by Philip Dunstan.

Three door implementations are included as separate levels in the project:
- Implementation_1: Nav Link Only Traversal
- Implementation_2: Nav Link when Closed, Navmesh when Open
- Implementation_3: Navmesh Traveral Only

Instructions for interacting with the example implementations:
- double-click on the "Open/Close" sign to toggle the door state.
- use the `show navigation` console command to toggle the navmesh debug draw in the editor or when the game is running
- use the `'` key to toggle the game debugger display when the game is running
- with the game debugger shown, use the `ai.debug.DrawPaths 1` command to show the navmesh path used by the NPC.
